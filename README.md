# 💸 Console Expense Tracker

A simple, interactive JavaScript console program designed to help you track your total budget, log daily expenses, and monitor remaining funds directly from your browser.

---

## 🎯 Features

* 💵 **Budget Setup:** Set a total budget with a fallback default value (`1000`) using Nullish Coalescing (`??`).
* ➕ **Expense Management:** Add new expenses dynamically while ensuring inputs are valid numbers.
* 🛡️ **Budget Guard:** Prevents spending more than the current available budget.
* 📊 **Live Balance Tracking:** View total expenses and current remaining balance in real time.
* 🔁 **Interactive Menu:** Menu-driven loop (`while` / `switch`) with clean labeled exits.

---

## 🚀 How to Run

1. Clone or download this repository.
2. Open your browser's Developer Tools (`F12` or `Ctrl + Shift + I` / `Cmd + Option + I`).
3. Go to the **Console** tab.
4. Paste the code from `script.js` into the console and hit **Enter**.
